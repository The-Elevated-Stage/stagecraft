# Stagecraft

Overarching documentation, reference designs, and expansion planning for [The Elevated Stage](https://github.com/The-Elevated-Stage) skill suite.

## Purpose

This is the meta-repository for the orchestra. It holds:

- **Reference designs** — Protocol specifications, task design templates, and architecture docs that describe how the overall system operates
- **Expansion planning** — Design documents for skills not yet built (e.g., Arranger)
- **Review archives** — Historical review findings and design notes

Individual skill repos hold their own skill-specific documentation. Stagecraft holds what spans across skills or predates a skill's existence.

## Directory Structure

```
docs/
  designs/    # Reference designs and specifications
  working/    # Active review findings and in-progress docs
  archive/    # Completed/historical documents
```
